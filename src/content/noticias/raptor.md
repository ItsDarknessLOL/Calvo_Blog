## En este video

En este video podras ver como realizar diagramas de flujos dentro de un software denominado como "raptor" yy su importancia ademas de un ejemplo de convertidor de decimal a hexadecimal.

## Resumen del video

Se explica cómo crear un algoritmo para convertir números decimales a hexadecimales usando Raptor. Se detallan los pasos para descargar el software, su instalación, y el uso de elementos como loops, decisiones, y asignaciones de variables. Se concluye con ejemplos prácticos para asegurar el correcto funcionamiento del convertidor.
